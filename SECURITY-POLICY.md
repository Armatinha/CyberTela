# Política de segurança — CyberTella

- Nunca adicionar segredos, credenciais, dados pessoais ou tokens ao repositório.
- Revisar alterações e executar testes antes de publicar.
- Preferir branches e pull requests para alterações sensíveis.
- Manter dependências atualizadas e permissões mínimas.
- Não integrar pagamentos nem conteúdo audiovisual sem validação técnica e direitos de distribuição.
- GitHub Pages é apenas hospedagem estática; autenticação, pagamentos e streaming exigem serviços apropriados.
- Não registrar dados sensíveis nos logs ou no navegador.
- Documentar mudanças e manter plano de reversão.
